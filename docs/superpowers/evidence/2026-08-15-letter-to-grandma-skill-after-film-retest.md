# Fresh Skill pressure test — multimedia feature retest

下面是一套可直接进入编辑、设计和视频制作的方案。核心原则是：电影做入口，档案承担历史事实，家庭故事只由家庭本人补齐。

# 图文专题方案

## 选题定位

主标题：

《一封信如何越过海：从〈给阿嬷的情书〉回到侨批与家族记忆》

副标题：

电影提供入口，档案确认对象；真正属于每个家庭的版本，仍要由家人自己讲述。

内容规格：

- 受众：看过影片或关心潮汕、侨乡、家庭记忆的普通读者
- 地域：以影片涉及的汕头、潮州、揭阳和东南亚传播节点为具名范围
- 年代：侨批历史背景以19—20世纪档案为主；电影传播时间线为2023—2026年
- 篇幅：正文约2000—2500字
- 视觉：6张仓库原创图＋1个公开视频链接＋1个可选家庭素材模块
- 文体：文化特写，不写成影评、票房稿或“潮汕人共同记忆”式泛化文章

![专题头图](D:/code/Project/潮汕人/.worktrees/llm-wiki-implementation/assets/letter-to-grandma-hero.png)

头图必须保留图注：

> 原创编辑插画；非历史照片、非电影剧照、非真实侨批复制件，人物不可识别。

## 可直接使用的导语

一封信如果同时带着问候和汇款，它承载的便不只是消息。侨批曾把海外谋生者与故乡家庭连接起来；今天，一部潮汕方言电影又让这种档案重新进入公共视野。但电影、档案和一个家庭真正经历过的往事，并不是同一种证据。我们从《给阿嬷的情书》出发，辨认一封信怎样成为故事，也把最后的空白留给每个家庭自己填写。

侨批兼具通信与汇款功能，相关档案于2013年进入 UNESCO 世界记忆名录；“世界记忆名录”不等于世界遗产或非物质文化遗产名录。[UNESCO 名录](https://www.unesco.org/en/memory-world/qiaopi-and-yinxin-correspondence-and-remittance-documents-overseas-chinese?hub=1081)

## 可直接生产的文章结构

### 01｜一张空白信纸：电影留下的入口（约220字）

写法：

- 从头图中两代人的手与空白信纸切入。
- 不先复述剧情，不使用电影台词。
- 提出专题问题：“一封跨海家书里，哪些是电影表达，哪些能回到档案，哪些只能由家人回答？”

视觉：

- `letter-to-grandma-hero`
- 图片下放“非电影剧照、非历史照片”声明。

### 02｜先给电影一个准确坐标（约300字）

可写事实：

- 国家电影局备案页列明影剧备字〔2023〕第2587号、备案单位、编剧蓝鸿春和“同意拍摄”；备案梗概只代表备案阶段，不能当作完成片的完整剧情。[备案页](https://www.chinafilm.gov.cn/dybalxgs/202312/t20231221_823053.html)
- 国家版权局预警名单列明影片于2026年4月30日上映，并要求未经许可不得通过网络提供或上传作品。[版权预警页](https://www.chinafilm.gov.cn/xxgk/gsxx/wggs/202604/t20260430_988295.html)
- 2026年5月17日举行影片及广东电影发展座谈会；报道中的调研经历属于主创自述，不是对电影全部历史细节的认证。[国家电影局座谈会页](https://www.chinafilm.gov.cn/xwzx/gzdt/202605/t20260521_990708.html)

视觉：

- `letter-to-grandma-timeline`
- 图注：“备案、上映、活动、海外放映是不同节点，不表示所有状态持续至今。”

### 03｜侨批不是一个怀旧道具（约400字）

正文顺序：

1. 解释侨批包含通信与汇款关系。
2. 写清信件、汇款凭证、递送网络、馆藏与数字化是不同环节。
3. 说明单件侨批只能证明具名寄收双方的一段经历，不能代表所有海外潮人家庭。
4. 明确电影怎样使用侨批，应写成“作品表达”；侨批是什么，则回到档案机构和 UNESCO。

视觉：

- `qiaopi-object-flow`
- 图注：“原创对象关系图，没有复制姓名、金额、地址、笔迹、邮戳或信件正文。”

可插入侧栏：

> 看一件侨批，应先问：寄件人是谁、收件人是谁、何时寄出、是否伴随汇款、经过什么递送环节、今天由谁收藏。缺少这些信息时，不替档案补故事。

### 04｜乡音进入银幕，也进入不同发行环境（约350字）

可写内容：

- 影片以潮汕方言／潮语组织叙事，但不能由此推导出“全片使用统一潮汕口音”。
- 导演在新华社专访中谈到侨批的剧作安排，以及泰文翻译、发音标记和演员语言准备。这只能表述为蓝鸿春对创作方法的说明。
- 仓库人工核验的必要时间码：
  - `00:03:55–00:04:45`：侨批在剧作结构中的安排
  - `00:06:40–00:08:05`：翻译、发音标记与跨语言表演准备
- 马来西亚 GSC 页面列出2026年6月18日上映、口语标记 `TEO`，字幕为马来文、中文和英文。这证明该院线页面的发行配置，不证明所有地区版本相同。[GSC 电影页](https://www.gsc.com.my/movie/dear-you/)
- 新加坡原音放映、字幕与政策讨论只写成2026年具名事件，不概括为海外潮人共同立场。[联合早报放映报道](https://www.zaobao.com.sg/news/singapore/story20260702-9299830)

视觉：

- `video-to-wiki-flow`
- 只给[新华社专访页面](https://www.news.cn/politics/20260516/b9e1d180b13f4fb1baddd16e4a286fd3/c.html)文字链接，不嵌入、下载、截帧或复制原音。

### 05｜三种地理，不能画成一条家族路线（约320字）

用 `letter-to-grandma-map` 分开三层：

- 汕头、潮州、揭阳：报道所列影片取景节点
- 中国侨乡与东南亚：侨批及社群的历史联系
- 马来西亚、新加坡：2026年具名放映节点

必须写明：

> 取景地、历史网络与当代放映不是同一种地理。示意图不是比例地图，也不是任何一个家庭的迁徙路线。

不要写“潮汕人都曾下南洋”。更安全的表述是：“侨批档案记录了部分海外移民与原乡家庭的跨海联系。”

### 06｜把页面交给一个真实家庭（约450字）

在用户提供家庭背景前，正文只保留如下待填卡片：

- 家中怎样称呼祖母？使用哪个汉字？当地如何发音？
- 家族具体来自哪个市、县区、镇村？
- 谁在什么年代离开？目的地是哪里？
- 家中保存的是普通家书、汇款凭证、侨批，还是后人转述？
- 谁拥有照片、信件或录音？允许公开、匿名公开、仅内部校对，还是不留存？
- 哪些细节来自亲历者，哪些是后辈转述？

可直接使用的过渡句：

> 电影能够提供进入往事的情感入口，却不能替任何家庭确认迁徙路线、称谓、口音或一封信的真伪。以下版本只属于这个家庭、这个地点和这个年代。

没有明确授权时，这一节继续使用空白问题卡，不放真实家庭照片。

### 07｜五种证据语气（约260字）

配 `evidence-layers`，逐项说明：

- 监管事实／历史档案：机构、日期和对象可核对
- 主创自述：必须写明是谁说的
- 作品表达：只说明银幕如何呈现
- 编辑综合：说明是多源并读后的有限判断
- 未知：家庭称谓、迁徙路线和当前放映状态不知道就留白

### 08｜结尾：电影结束之后，信仍要回到人手里（约150字）

可直接使用：

电影把侨批重新带到更多观众面前，但一封真实的信仍有具体寄件人、收件人、年月和保存者。专题最后不追问“潮汕人是不是都一样”，而只问一个更小的问题：你家有没有一封仍被记得的信？如果有，先问清它属于谁，再决定是否让更多人看见。

# 需要家庭或当地人确认的内容

| 内容 | 应由谁确认 | 未确认时的处理 |
|---|---|---|
| “阿嬷”的实际称呼、用字和读音 | 家庭长辈＋该地潮语使用者 | 正文只沿用片名，不制作方言教学字幕 |
| 县区、镇村和家族迁出地 | 家庭成员＋可核户籍／信件／族谱资料 | 地图不画家族路线 |
| 出发年代、目的地和中转地 | 亲历者、后代及具体档案 | 标 `unknown`，不根据电影补齐 |
| 一件材料是否属于侨批 | 档案人员或能辨认信件、汇款凭证和递送标记的人 | 只称“家书／旧纸件”，不先定性 |
| 照片中的人物、地点和年代 | 照片提供者及当地知情者 | 不写具体身份和地点 |
| 家庭礼数、祭祖或宗教场景 | 当事家庭、当地长辈或社区组织 | 不重演、不列统一步骤、不安排演员演示 |
| 是否允许公开姓名、脸部、地址、笔迹 | 素材权利人及画面中的当事人 | 默认匿名、遮挡或不用；未成年人需监护授权 |

用户材料只用于本次生产并停留在本地覆盖层；“稍后提供”不等于授权公开或持久保存。

## 60秒口播全文

> 一封信里同时装着问候和汇款，它还是普通家书吗？  
> 这叫侨批：连接海外谋生者与故乡家庭的通信和汇款档案。  
> 电影《给阿嬷的情书》用侨批和潮语组织故事，2026年4月30日上映。但电影是作品，不是历史档案。

> 汕潮揭取景，不等于每个地方、每个家庭都有同一种口音和迁移经历。  
> 电影是入口，真信把记忆带回家。
