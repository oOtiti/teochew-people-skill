# 短视频口播与分镜

## 60秒结构

| 时段 | 口播任务 | 画面任务 | 证据标签 |
| --- | --- | --- | --- |
| 0—6秒 | 提出一个准确反差 | 一个来源内特写 | `source_detail` |
| 6—18秒 | 限定定义、地点、年份 | 地图／日期卡 | `editorial_structure` |
| 18—38秒 | 两至三个可核事实 | 人、动作、器物、声音、空间 | 每镜 source ID |
| 38—50秒 | 展示另一地／家庭差异 | 对照，不混素材 | `varies` |
| 50—57秒 | 说明未知或实时状态 | unknown／last_checked 卡 | `unknown` |
| 57—60秒 | 来源与下一步 | topic + raw ID | `citation` |

## 分镜字段

每镜至少写：`shot`、`duration`、`location`、`people`、`action`、`object`、`sound`、`source_id`、`rights`、`safety`。`source_id` 为空的转场必须标 `editorial_structure`，不能配事实性旁白。

来自视频的镜头另加 `timecode`、`responsible_party`、`claim_type` 和 `transcript_status`。`speaker_claim`、`narration`、`subtitle`、`frame_observation` 不可混在一个字段；自动转录经人工回听前不得进入稳定旁白。完整链路见[视频素材转 Wiki](./视频素材转Wiki.md)。

## 声音

分别收环境、人声、动作与音乐：英歌可分鼓、木槌、脚步和观众；潮州音乐分单件乐器、合奏和环境；工夫茶可留水沸、壶盖与杯声。不得用一段“古风音乐”代替地方声音，也不得未授权复制戏曲或电影音轨。

## 动作和顺序

来源描述的一次行进、冲泡、扫描或制作顺序，只属于该项目／现场。剪辑顺序是创意，不得改写成统一仪式或教学。宗教动作不安排演员重现，高强度表演只由专业队员完成。

## 三个可直接套用的方向

- **拜老爷 vs 营老爷**：家庭／庙宇敬神与社区巡行对照，地图和日历作编辑层，绝不列统一神明或供品。
- **侨批**：信封—邮戳—汇款—扫描台，所有文字来自获授权具体档案。
- **英歌**：快鼓—木槌—队形—一次具名活动，标队伍、地点和年份。
- **《给阿嬷的情书》**：影片只作入口，用原创时间线、侨批对象图和语言版本图说明电影／档案边界；新华社访谈只保留时间码转述，影片本体、海报、台词与音乐不进入仓库。（`xinhua-letter-to-grandma-video-2026`、`ncac-film-copyright-warning-letter-to-grandma-2026`）

## 发布前

核实活动、路线、人物、版权、肖像和现场安全；检查字幕没有“潮汕人都”“正宗必须”“已申遗”等越界表达。电影、新闻、档案和表演素材逐项标 `official_or_licensed`、`link_only` 或 `editorial_original`；最后一屏显示核验日和主要 source IDs。
