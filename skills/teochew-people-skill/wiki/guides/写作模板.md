# 写作模板

## 文化解释（300—600字）

```text
[地方/年份]的[人物]正在[有来源的动作]。
[主题]在这里指[限定定义]（source ID）。
来源确认：[事实1]；[事实2]。
另一地/家庭的差异是：[差异]（source ID）。
现有资料不能确认：[unknown]。
```

## 深度文章

```text
标题：一个具体物件或人物 + 一个可回答的问题
导语：来源内场景，不虚构心理
第一节：定义、范围、历史证据
第二节：两个地点/年代的个案
第三节：当代变化与反例
第四节：生产细节、未知与来源表
```

## 展览／教育前言

```text
本文以汕头、潮州、揭阳为核心，并在有来源时连接海外潮人社群。
选取[4—6个有来源主题]，展示家、乡、语言、技艺和远方如何在不同地方被保存与改写。
各地各家做法不尽相同，展项不构成统一民俗手册。
```

## 家庭祝福

```text
今天一家人坐在一起，记住长辈的照顾，也祝[当事人]平安、长进、彼此尊重。
具体礼俗依本家选择；这段祝福不规定供品、日程、座次或禁忌。
```

## 菜品／工艺介绍

```text
[制作者]在[地点]选用[已确认材料]，现场动作是[来源或采访支持]。
这是一位制作者/一个项目的版本，不代表所有潮汕家庭或工坊。
```

## 事件状态卡

```text
事件：
发生日期：
当前状态：open / closed / superseded
last_checked：YYYY-MM-DD
官方来源：
能证明：
不能证明：
关联 durable topic：
```

## 使用规则

模板只决定信息顺序，不提供文化事实。所有方括号必须由 topic/raw 或经授权访谈填充；没有证据就保留 unknown，不用“古法”“祖训”“人人如此”补位。
